# Weight Converter (Python)

## Description
This repository contains a clean, beginner-friendly Python project for converting weight between **kilograms** and **pounds**. The project is organized with a professional structure so source code, examples, notes, and assets are separated clearly.

## Features
- Convert kilograms (`k`) to pounds (`lbs`)
- Convert pounds (`lbs`) to kilograms (`k`)
- Handles invalid unit input safely
- Interactive command-line execution
- Example script for quick demonstration
- Clean repository structure for learning and extension

## Technologies Used
- Python 3
- Standard Library only (no external dependencies)

## How to Run
From the repository root:

1. Run the interactive converter:
   ```bash
   python src/weight_converter.py
   ```

2. Run the example script:
   ```bash
   python examples/weight_converter_example.py
   ```
